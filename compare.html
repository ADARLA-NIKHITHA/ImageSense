How Image Comparison Works

This project uses SSIM (Structural Similarity Index) to compare images based on structure, brightness, and contrast instead of just pixels.

Steps Involved:

  1. Upload two or more images
  2. Images are stored temporarily
  3. SSIM algorithm compares image pairs
  4. Similarity score is calculated
  5. Results displayed in percentage

Result Interpretation:

  • 🟢 80% – 100% → Highly Similar
  • 🟡 50% – 79% → Moderate Similarity
  • 🔴 Below 50% → Different Images
